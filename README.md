# ChatGPT Projects

A workspace for turning James's ideas into working prototypes, tools and experiments with ChatGPT.

Each project lives in its own folder at the repository root:

```text
project-name/
├── README.md
├── src/
└── ...
```

The repository root is reserved for shared guidance and configuration. It is not itself an application.

## Working approach

- Create a new folder for each distinct project.
- Give every project its own README with its purpose, setup and usage instructions.
- Keep projects self-contained unless sharing code provides a clear benefit.
- Use sensible defaults and build a working first version when the brief leaves minor details open.
- Use a dedicated branch and pull request for substantial work.
- Never commit secrets, credentials, personal data or generated build output.

Project-specific instructions may be added in an `AGENTS.md` file inside that project's folder.
