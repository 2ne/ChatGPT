# Reception maths

Reception is the start of the path in [maths.md](./maths.md), not a separate curriculum.

The mathematics Early Learning Goals are covered by these categories:

| Early Learning Goal | Categories |
| --- | --- |
| Number — understanding to 10, composition, subitising to 5, bonds to 5, some bonds to 10, doubles | `cat-r-to-5`, `cat-r-to-10` |
| Numerical patterns — count beyond 20, compare quantities to 10, odds and evens, doubles, equal sharing | `cat-r-to-10`, `cat-r-count-on` |

Node 1 is `eyfs-count-5`. Literacy and the other areas of learning are out of scope in this maths phase (they are later-pathway subjects, not this file). Each node still has Easy / Medium / Hard in the app.
