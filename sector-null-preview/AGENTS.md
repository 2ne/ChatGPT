# Preview boundary

This is the independent Room 2 preview. Implement preview changes here, build
with `npm run build`, and deploy through the existing Pages workflow to
`/sector-null-preview/`. The public game source is `../sector-null/` and must not
be changed or replaced as part of preview work. Keep `?dev=bay` working.

Room 2 currently supports exploration after the wave-10 handoff; combat is not
yet wired up. Do not describe the room as having working waves or an active
Tesla weapon until those features are implemented.
